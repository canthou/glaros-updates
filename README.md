# Glaros CMS — update channel

Public download channel for the Glaros CMS desktop app. The source code is private; this
repository holds only what installed copies of the app need to update themselves:

- `latest.json` — the newest version and its download URL. Installed apps (1.8.12+) fetch
  `https://raw.githubusercontent.com/canthou/glaros-updates/main/latest.json` on startup.
- [Releases](https://github.com/canthou/glaros-updates/releases) — `Glaros.zip` for each version.

No source code, databases or customer data are ever published here.
